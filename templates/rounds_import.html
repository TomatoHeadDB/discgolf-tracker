A scorecard usually has everyone in your group on it — we only import rows matching this exact name, so your friends' scores stay out of your stats.

How to export from UDisc

  1. Open the UDisc app and tap More, then Scorecards.
  2. Tap the ☰ menu in the top-right corner.
  3. Select Export to CSV.
  4. Save the file somewhere you can upload it from here (email it to yourself, save to cloud storage, etc.).

This export includes your entire round history, not just new rounds — that's fine, re-importing the same file (or an overlapping one) won't create duplicates.
